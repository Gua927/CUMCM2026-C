\section{问题重述}

\subsection{问题背景}

含光伏与储能的非孤岛式微网可以通过外部电网补充电力，也可以利用储能调节不同时段的供需关系。光伏出力与小区用电需求在时间上并不总是匹配：当光伏出力超过即时需求时，剩余电能需要储存或弃用；当光伏不足时，则需要外网购电或储能放电。与此同时，外网电价的时段差异使相同电量在不同时间具有不同的购入成本。因此，在满足负荷的前提下协调购电与充放电，是降低微网运行费用的关键。

储能能够转移电能，但其容量和充放电功率有限，且转移过程存在损耗。当前充放电决策不仅影响本时段购电量，还会改变后续时段可用的电量与空余容量。实际运行中，未来负荷、光伏出力及电价又无法完全预知，计划不足可能引发高价紧急购电，日内修改计划也需承担额外费用。由此，微网调控需要同时处理能量的跨时段配置、不确定条件下的购电承诺以及新信息到达后的计划修正。

\subsection{研究任务}

根据题目给定的设备条件与交易规则\cite{problem-c}，本文研究以下四个相互关联的问题。

\begin{enumerate}[label=（\arabic*）,leftmargin=2.8em]
  \item 当每日电价与负荷模式固定、当日光伏预测已知时，在 $0{:}00$ 制定全天计划购电及储能充放电策略，满足日初、日末储电量相等的要求，并给出指定时段和全天的购电量、费用及储能运行结果。
  \item 当负荷与光伏出力随日期变化时，在每日 $0{:}00$ 制定当天计划购电量。计划费用按承诺电量计算，供电缺口以对应时段电价的 $5$ 倍紧急补购，要求给出各日策略及指定日期的详细结果。
  \item 在每日 $0{:}00$、$6{:}00$、$12{:}00$、$18{:}00$ 获得未来 $24$ 小时光伏预报的条件下，制定日前计划与日内调整策略，综合考虑上调购电、下调违约和紧急补购费用，并分析增加预报发布时点的必要性。
  \item 当外网电价实时波动时，分别扩展问题二和问题三的策略，研究价格不确定性对购电安排、储能使用及运行费用的影响。
\end{enumerate}

\section{问题分析}

四问的共同目标是在满足用电需求的条件下减少购电支出。它们共享能量守恒、储能状态转移和设备边界，区别在于未来信息的可见程度、合同的调整权限以及费用的组成。因此，本文将四问统一为受信息约束的跨时段资源配置问题：首先确定物理可行域，再根据可用信息描述未来不确定性，最后通过相应费用函数选择购电与充放电策略。

\subsection{问题一的分析}

问题一给出了当天的电价、负荷及光伏预测，可以将这些序列视为确定性输入。由于储能电量在相邻时段之间传递，一天内的 $144$ 个时段不能分别独立优化。特别是日初、日末储电量相等的条件，要求当天的低价充电、光伏消纳与高价放电在整体上协调，避免通过消耗初始储能获得不可持续的费用优势。

该问的难点在于确定有限电量和空余容量应保留给哪些时段。低价时段充满电池可能减少随后光伏的存储空间；提前放电虽然能够降低即时购电量，却可能增加更高电价时段的购电需求。因此，需要以全天为优化范围，在能量平衡、充放电效率、容量和功率约束下联合决定购电与储能运行。

当采用时段电量作为决策变量时，购电费用、能量平衡和储能状态转移均为线性表达式。若用二元变量限制充放电互斥，可建立混合整数线性规划；取消互斥则得到其线性规划松弛。问题一由此提供四问共用的物理模型与确定性求解基础，但其基于给定预测的最优费用不能直接视为其他问题真实运行费用的下界。

\subsection{问题二的分析}

问题二的关键变化在于日前决策时无法得知当天完整的真实负荷与光伏轨迹。全年历史附件虽然可用于离线研究，但对某日 $0{:}00$ 的决策而言，当天及此后的实测值尚不可用。因此，应严格区分决策输入与事后评价数据，以此前历史形成预测或条件情景，再在真实值逐步到达后计算执行结果。

普通购电与紧急补购的价格差异使预测误差具有不对称的经济影响。计划偏高会产生未利用电量的购电支出，计划偏低则可能触发 $5$ 倍电价补购。由此，单纯追求预测均方误差最小不能充分体现调度目标，需要将预测偏差转化为实际费用，在多购电的代价与不足补购的风险之间权衡。

储能进一步增强了这种权衡的时序性。孤立的预测偏差可能由电池吸收，连续多个时段的光伏不足则可能使储能逐步耗尽。因此，本文以净负荷为主要调度对象，保留负荷与光伏误差的相关性及其跨时段连续性，在固定日前合同的条件下研究因果的储能运行策略。该问固定的是普通购电计划，本文不额外假定储能动作必须全天锁定。

\subsection{问题三的分析}

问题三允许在运行过程中获得新的光伏预报，并据此调整尚未交付时段的购电计划。相较于问题二，系统除了继承实际储能电量，还必须保留日前合同及其后续版本，因为同样的购电需求在不同合同基础上可能产生不同的调整费用。

更新预报能够改变对未来缺口的判断，但预测变化并不必然要求修改合同。当电池能够吸收偏差时，重排充放电可能已经足够；当预期紧急补购的减少超过调整代价时，增购才具有经济意义。因而，该问适合采用滚动优化：在允许的时点更新信息与状态，重新计算未来决策，并保留不调整合同的选择。

对新增预报时刻的评价也应以经济后果为依据。需要区分初始预报的价值、后续信息对储能运行的价值和合同调整权限的价值，避免将三者混合归因于预测精度提高。此外，题面未明确下调电量的原购电费是否退回，结算解释会直接影响下调是否有利，必须在费用模型中单独说明。

\subsection{问题四的分析}

实时波动电价既影响当期付款，也改变储能电量的未来价值。低价时段的购电未必应立即使用，高净负荷与高电价同时出现则可能显著放大紧急补购费用。因此，第四问需要在负荷和光伏不确定性的基础上考虑价格风险，研究三者的共同变化对策略的影响。

本文将未来实时电价视为未知量，仅允许使用已观测价格及历史信息构造价格预测；全年真实价格用于逐时结算。若直接将当天完整价格序列作为日前输入，相当于额外赋予未来价格信息，应作为不同信息条件下的对照。扩展时保持问题二与问题三各自的合同权限、设备约束和评价边界一致，使比较能够反映价格信息与交易机制的作用。

\subsection{总体建模思路}

本文采用“物理约束统一、信息逐层扩展、费用分别结算”的建模方式。以储能电量刻画跨时段物理联系，以信息集限制可执行决策，以合同状态记录已作出的购电承诺。问题一确定能量配置的基础结构，问题二引入预测不足的经济风险，问题三增加预报更新与有偿修正，问题四将电价纳入条件预测体系。四问的对应关系见表~\ref{tab:overall-framework}，信息到达、决策时刻与结算项的时间关系见图~\ref{fig:framework}。

\section{模型假设}

为突出购电与储能配置的主要矛盾，作如下假设。设备参数直接采用题面给定值，涉及题意解释的约定另行注明。

\begin{enumerate}[label=（\arabic*）,leftmargin=2.8em]
  \item 将微网视为单一能量节点，以 $10$ 分钟为调度时段，使用时段代表功率计算电量，不单独描述节点间潮流、电压和线路损耗。该简化与题目提供的汇总负荷及光伏数据尺度一致。
  \item 不考虑向外网售电，光伏过剩部分允许弃用；未利用的普通计划电量可不取用，但仍按有效合同结算。光伏弃电与未利用计划电量分别记账，不设题面未给出的处置费用。
  \item 充、放电效率分别取 $\eta_c=\eta_d=0.9$，忽略自放电及效率随功率变化的影响，并禁止同一时段同时充放电。此处将题面的 $90\%$ 解释为双侧单程效率，对应往返效率为 $0.81$。
  \item 外网能够补足剩余负荷缺口，不额外设置题面未给出的外网功率上限。紧急购电仅用于满足当前负荷，不能用于主动充电套利。
  \item 区分日前合同决策与时段内运行响应。普通合同按各问规定的时点制定或调整，储能可依据已观测供需反馈；时段内响应按快速控制近似处理，不将本时段事后平均值作为时段开始前已知的信息。
  \item 光伏预报在标注发布时刻即可获得。对未来的规划只使用已发布预报与已到达历史数据，不预先使用未来实测值；第四问的未来实时电价同样未知。
  \item 问题二至四连续运行，次日初始储电量等于前一日实际末态。除问题一外，不强制每日恢复初始电量；通过跨日规划及明确的远端处理反映后续运行需求，不把24时当作系统终点。
\end{enumerate}

效率的另一种解释、计划电量必须交付、观测存在延迟等情形会改变运行约束，属于上述假设的适用边界。第三问的调整结算与第四问的价格结算时点在对应模型中具体规定。
