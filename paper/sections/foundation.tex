\section{问题重述与分析}

\subsection{问题背景与重述}

微网是为促进光伏等分布式能源就地消纳而发展起来的小型发用电系统。含光伏与储能的小区微网既要在每个时段满足负荷，又要尽量降低向外网购电的费用。光伏出力集中在日间，负荷高峰却出现在早晚；储能可以把低价或富余时段的电量转移到高价或短缺时段，但受容量、功率和转换损耗限制。问题二要求每天0时提前制定各时段的计划购电量，并按该计划量付费；问题三进一步允许在预报更新时有偿调整尚未执行的计划。预测偏差因此会转化为计划电量闲置或高价紧急补购。本题的核心是在信息不完全、储能有限且计划调整有代价的条件下，协调计划购电与储能充放电，使实际购电费用最低。

题目给定储能额定容量$12000\ \mathrm{kWh}$、允许储电量$1200$--$10800\ \mathrm{kWh}$、最大充放电功率$5000\ \mathrm{kW}$、充放电效率$90\%$及2025年1月1日0时储电量$6000\ \mathrm{kWh}$，调度步长为10分钟，并按信息条件与交易权限设置四个递进的问题\cite{problem-c}：
\begin{enumerate}[label=（\arabic*）,leftmargin=2.8em]
  \item \textbf{问题一：}给定某日分时电价、负荷与光伏预测功率（附件1），在0时制定当天购电与充放电策略，要求供电不低于负荷、0时与24时储电量相同，购电费最小。
  \item \textbf{问题二：}电价不变，负荷与光伏逐日变化（附件2），仅凭历史数据在每日0时制定当天的计划购电量；计划电量全额付费，缺口按交易时刻电价的5倍紧急购电，2025年2月1日至12月31日连续运行。
  \item \textbf{问题三：}每日0、6、12、18时获得未来24小时整点光伏预报（附件3），可据此调整尚未执行时段的计划购电量：上调部分按1.5倍电价计费，下调部分按0.5倍电价结算；并分析是否需要引入0时以外的预报。
  \item \textbf{问题四：}外网电价实时波动且未来未知（附件4），在波动电价下分别重新求解问题二与问题三的购电策略。
\end{enumerate}
各问均须给出指定时段的购电、充放电与紧急购电结果及完整策略工作簿，评价范围由单日优化扩展至全年连续运行。

\subsection{问题分析}

\textbf{储能使当前决策与未来机会相互制约。}低价充电虽可减少晚高峰购电，却可能占用次日光伏所需的容量；提前放电虽能缓解当前缺口，也可能增加后续高价补购。因此不能按时段孤立决定动作，也不能仅凭峰谷价差判断收益，而应以储电量贯通各时段，在效率与功率约束下比较保留电量和腾出容量的机会成本。连续运行中，24时只是日期边界而非系统终点。

\textbf{预测误差的经济后果不对称。}计划购电量偏高时，未取用电量仍须付费；计划购电量偏低时，缺口须按更高价格购买。最小预测误差因而未必对应最低费用，计划量应同时考虑误差分布与不足代价。预测与误差校准还受时间约束：尚未结束的目标日不能提供完整残差，尚未发布的预报也不能提前进入规划。

\textbf{信息更新只有通过可执行的动作才能转化为收益。}预报变准以后，微网可以用储能吸收偏差，也可以付费调整计划购电量，二者边际代价不同。评价新信息的价值必须控制计划调整权限、状态反馈和结算口径；实时价格出现后，还应区分“同一策略因结算价变化而增支”与“利用价格预测改变策略而节费”，否则易把权限扩展的收益误归为预报改善。

\subsection{总体思路}

本文以能量守恒、储能状态与购电费用账本为统一骨架，按“风险预测—辅助规划—因果执行—独立核验”组织四问（图~\ref{fig:framework}）。\textbf{问题一}以10分钟电量为变量建立混合整数线性规划，先最小化购电费，再在费用近等价方案中减少储能吞吐与购电波动，用线性松弛下界核验最优性。\textbf{问题二}由历史成对残差构造净负荷风险轮廓，以非对称代价确定计划余量，采用48小时辅助规划但仅确定当天的计划购电量，储电量跨日连续。\textbf{问题三}按发布时间接入外部预报，由上调与下调的边际费用导出调整带，在6、12、18时依据实际储电量有偿修改剩余时段的计划购电量，再以逐层消融归因收益来源。\textbf{问题四}加入因果价格预测，规划用预测价、账单按交付时段实价核算，先固定决策识别结算效应，再放开策略响应并比较计划固定与有偿调整两类机制。全部策略均通过物理、费用与信息边界的独立核验。

\section{模型假设}

设备参数采用题面给定值；为使模型可解且口径一致，作如下假设与解释约定。

\begin{enumerate}[label=（\arabic*）,leftmargin=2.8em]
  \item 将微网视为单一能量节点，以10分钟为调度时段，用时段代表功率计算电量，不描述节点间潮流、电压与线路损耗。
  \item 微网不向外网售电，过剩光伏允许弃用；未取用的计划电量仍按相应计划购电量结算。光伏弃电与未利用计划电量分别记账，不设题面未给出的处置费用。
  \item 题面的充放电效率 $90\%$ 按国家标准理解为往返能量效率，即放电能量与充电能量之比\cite{gbt-36549,gbt-36276,gbt-36558}，对称拆分为 $\eta_c=\eta_d=\sqrt{0.9}\approx0.9487$；忽略自放电及效率随功率的变化，同一时段不同时充放电。双侧各 $0.9$（往返 $0.81$）的另一种读法作为敏感性对照。
  \item 外网总能补足剩余缺口，不设题面未给出的外网功率上限。紧急购电只用于满足当前负荷，不得用于主动充电套利。
  \item 区分计划购电决策与时段内运行响应：计划购电量按各问规定的时点制定或调整，储能则依据已观测的供需反馈动作；时段内响应按快速控制近似处理，不把本时段事后平均值视为时段开始前已知。
  \item 光伏预报在标注发布时刻即可获得。规划只使用已发布预报与已到达历史数据，不预先使用未来实测；问题四的未来实时电价同样未知。
  \item 问题二至四连续运行，次日初始储电量等于前一日实际末态。除问题一外不强制每日恢复初值，而以跨日规划和明确的远端处理反映后续需求，不把24时视为系统终点。
\end{enumerate}

问题三的下调结算口径与问题四的价格时点在相应章节说明；效率、交付义务和观测延迟的变化属于模型适用边界。
