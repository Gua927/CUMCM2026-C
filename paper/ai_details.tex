\section{具体使用目的和环节}

AI 工具在本参赛作品中的使用集中于以下环节：

\begin{itemize}
\item \textbf{资料与题面整理。}整理题面条件、附件结构与参数配置，区分题面事实与建模假设，形成研究路线文档。
\item \textbf{建模讨论。}就储能时序耦合、信息可用边界、结算口径、风险度量等问题进行讨论与方案比较，供人工决策。
\item \textbf{代码审查与调试。}审查人工撰写的预测器、线性规划与贪心执行器、跨日回放、敏感性与对照实验、结果工作簿写出及校验脚本。
\item \textbf{图表绘制。}按统一风格从已归档数值重绘正文图形，并生成排版所需表格。
\item \textbf{论文撰写与语言润色。}润色与修改章节文字、摘要、图注，统一术语与符号，控制篇幅与排版。
\item \textbf{自查与审计。}复核物理与费用恒等式、因果性（信息可用边界）、交叉引用与页面排版。
\end{itemize}

\noindent 核心建模思路、口径选择与最终取舍由人工作出，具体见第 \ref{sec:adopt} 节。

\section{主要提示方式与使用过程}

参赛队以中文自然语言在本地项目目录内下达任务，同时提供题面 PDF、四个附件数据、\texttt{problem.json} 参数配置以及项目工作规范文件；工具在同一目录内读写文件、运行程序与测试，并把每次操作的输入、产物与哈希写入运行记录。提示以“目标 + 约束 + 交付物”的方式给出，并要求工具在结论不确定或出现不利结果时如实说明，不得以更优的表述掩盖。

典型提示示例：

\begin{itemize}
\item “参考人工实验，润色和修改问题重述、问题分析等部分。”
\item “日末储能的处理改用 48 小时滚动方案，并与 24 小时方案作同参对照。”
\item “按中国国家标准判断题面‘充放电效率 90\%’应读作单侧效率还是往返效率，给出依据。”
\item “核查第二问及其后各问是否只做规划而未做预测，预测训练是否读取了决策日之后的数据。”
\end{itemize}

\section{对 AI 输出的采纳、人工修改和核验}\label{sec:adopt}

\subsection*{采纳与人工修改}

参赛队对工具的每一项输出逐项审阅后决定取舍，以下关键判断由参赛队作出并要求工具据此修改：

\begin{itemize}
\item 附件模板的时段起点与午夜日循环解释、附件二与附件四按连续日历时标解释；
\item 问题二日末储能改用 48 小时滚动方案（工具原实现为终端系数法，被否决后重做）；
\item 问题三结算改以字面读法的退款口径为主、不退款口径为对照；
\item 依据 GB/T 36549—2018 等标准，将题面 90\% 读作往返效率并对称拆分为 $\eta_c=\eta_d=\sqrt{0.9}$，双侧各 0.9 降为敏感性对照，四问据此全部重算；
\end{itemize}


\subsection*{核验方式与结果}

除语言润色外，AI 参与完成的内容均经以下独立核验：

\begin{itemize}
\item \textbf{手算小算例。}对可手工验算的小规模系统重算充放电、SOC 与三项费用，与程序结果比对。
\item \textbf{物理与费用重算。}对全部回放轨迹独立重算能量平衡、功率与容量约束、计划购电费、偏差费与紧急购电费。
\item \textbf{最优性核验。}线性规划原始--对偶核验与松弛下界检查。
\item \textbf{因果性审计。}\texttt{make audit-causality}：逐日将决策日及其之后的附件数据替换为随机数后重建预测与计划，与归档逐时比对。问题二、问题三及问题四的两条策略各检验 334 天，全部通过，计划的最大偏差为 $2.3\times10^{-12}$~kWh 量级。
\item \textbf{专项复核。}对问题二指定日期出现的三个零紧急购电值，由原始输入独立重算执行轨迹，确认其原始累计值为 $10^{-13}$~kWh 量级的浮点噪声，且全年被提取阈值排除的正值合计仅 $1.37\times10^{-10}$~kWh（见 \path{doc/Table9-Audit.md}）；另对模板时段语义与备选调整结算口径作只读对照核算。
\item \textbf{排版核验。}编译后逐页渲染检查交叉引用、图内最小字号、裁切与重叠。
\end{itemize}


\section{人工责任确认}

本参赛队已对 AI 参与完成的内容逐项进行人工审查与核实，审查范围覆盖模型假设与建模思路、目标函数与约束的推导、程序实现与参数设置、数值结果及结果工作簿、论文部分文字与图表。核心建模与分析由参赛队主导，AI 输出经参赛队判断后采纳或否决，并按参赛队意见修改。
