# 模型模块划分

建议按以下文件逐步实现，避免把四问写成一个不可维护的大脚本：

- `common.py`：功率平衡、SOC 转移、充放电互斥、单位换算和费用分解；
- `problem1.py`：单日确定性线性/混合整数优化；
- `problem2.py`：基于历史负载与光伏误差的日前计划及紧急购电；
- `problem3.py`：0/6/12/18 时滚动更新的模型预测控制或随机优化；
- `problem4.py`：将实时电价接入问题 2、3，并比较收益与风险；
- `evaluation.py`：四个指定日期、全年费用、紧急购电、SOC 可行性及敏感性分析。

所有模块应使用同一套 10 分钟时间索引和单位约定：功率为 kW，单时段电量为 kWh，SOC 为 kWh，价格为元/kWh。
