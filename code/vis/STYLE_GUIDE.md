# 科研图形统一规范 v1.0

本规范服务于“基于信息集的风险感知闭环储能调度”论文。目标是清楚、克制、可复核，而不是装饰性地模仿某张期刊插图。参考 Nature 的科学图形指导与 NeurIPS 的清晰度、黑白可读性要求；**不存在一套统一的“CNS / NeurIPS 官方绘图风格”**。本项目保留数学建模竞赛的中文论文版式，不套用其他刊会的页面尺寸、正文字体或投稿规定。

## 1. 唯一配置与复用接口

- `code/config/visual_style.json`：颜色、字体、字号、线宽、物理尺寸和导出格式的唯一配置源。
- `code/vis/style.py`：加载样式、子图编号、坐标轴、导出前检查和网页主题。
- `code/vis/publication.py`：从已核验数据生成问题一、二的论文图。
- `code/vis/build.py`：只重绘、不求解的发布与归档流程。
- `Agent.md`：将本规范作为当前与未来绘图的强制入口。

新增问题三、四图形时必须使用上述接口。不得复制一套独立配色，或在不同文件内散落修改 `rcParams`。新增语义颜色先修改配置和本表；改变共同样式须增加版本号并重绘全文相关图。

## 2. 语义配色与冗余编码

颜色先表达“是什么”，再考虑美观。同一上下文中的同一变量，全文颜色固定。

| 物理或费用变量 | 配置键 | 颜色 | 辅助编码 |
| --- | --- | --- | --- |
| 外网计划电 / 计划费 | `grid` | `#0072B2` 蓝 | 实线 / 实心条形 |
| 光伏 | `pv` | `#E69F00` 金 | 半透明面积，注明预测或实际 |
| 储电量 / 放电 | `soc`, `discharge` | `#009E73` 青绿 | 状态折线 / 零轴上方填充 |
| 充电 | `charge` | `#56B4E9` 天蓝 | 零轴下方填充 |
| 紧急购电 / 紧急费 | `emergency` | `#D55E00` 朱橙 | 斜线纹理，不能只靠红绿差异 |
| 电价 | `price` | `#CC79A7` 紫红 | 单独价格面板 |
| 负荷 / 净负荷 | `load` | `#3D4651` 深灰 | 虚线 |
| 无储能基线 | `baseline` | `#7D8896` 灰 | 点线、三角或纹理 |

策略比较图是另一明确的图例上下文：风险主策略为蓝色圆点实线，点预测为朱橙方点虚线，无储能为灰色三角点线，参考跟踪为紫色菱形，滚动控制为青绿倒三角。不得把策略颜色误解释为某一电源分量。实现中的 `STRATEGY` 映射是这一规则的统一入口。

充放电可共享设备语义，但必须依靠正负方向、标注或线型区分。强制保留黑白阅读的第二通道。禁止彩虹色、渐变装饰、三维条形、阴影浮雕和无解释的双纵轴。

## 3. 物理尺寸与排版

全文图宽为 **160 mm**，与本项目 A4 正文版心一致；独立半宽图为 **78 mm**。高度由信息量决定，不挤压数据以凑模板。

| 元素 | 最终印刷尺寸 |
| --- | --- |
| 数字、英文 | Arial；数学回退 DejaVu Sans |
| 中文 | Microsoft YaHei |
| 刻度和基础文字 | 8.5 pt |
| 轴标题、子图短标题 | 9 pt |
| 图例、必要注释 | 8 pt，禁止更小 |
| 子图编号 | 10 pt，加粗小写 `a, b, c, …` |
| 普通数据线 / 强调线 | 1.1 / 1.5 pt |
| 坐标轴 / 网格 / 参考线 | 0.6 / 0.4 / 0.7 pt |

白底，去掉上、右边框，网格低对比且仅服务读数。子图字母与标题使用统一物理间距。不要把论文标题重复放进图内；完整条件放在图注。

160 mm 图在 LaTeX 中以 `width=\textwidth` 引入，使用矢量 PDF。**字号以插入论文后的大小为准**，不能先画巨大画布再缩至三分之一。需要半宽图时应重新按78 mm排版，而不是直接缩小全宽图。中文字体缺失时明确报错，不接受方框字或静默替换。

## 4. 坐标、数据与比较公平性

1. 10分钟平均功率、合同、电价采用区间阶梯，覆盖完整 `[0,24]` 小时；SOC连接145个边界状态。SOC折线不等于对功率曲线平滑。
2. 延续已确认的日循环起点时标，不因绘图改变日期归属。时标假设在正文说明。
3. 功率默认MW，储电量默认MWh，现金费用按尺度标注元或万元。换算仅作用于显示，不改源数据。
4. 条形图必须从零开始；敏感性折线与风险散点可采用非零轴，但图注必须避免夸大效应。
5. 用来直接比较的日期面板统一坐标范围；不得逐面板自动缩放而不给提示。
6. 电源、储能状态、电价分面展示，避免双轴制造伪相关。
7. 图例放在留白或图外，不遮挡有效曲线。优先3条主线，更多策略转为条形、散点或分面。
8. 禁止为美观平滑原始曲线、删去峰值、平移实测数据、选择性隐藏失败日。模型内部预测平滑与显示端装饰性平滑必须区分。

## 5. 不确定性与图注

没有统计依据，就不画置信带。敏感性连线只连接实际求解点，不能冒充统计置信区间。

区间图必须交代：估计对象、样本单位、方法和置信水平。当前问题二图中的误差线为日配对节费的七日循环块重采样95%区间，不是标准差；只描述该年度历史回放，不代表跨年保证。CVaR95为日紧急费用的经验尾部指标，与费用差的置信区间不是同一对象。

图注建议采用“研究对象；a/b等子图映射；单位与比较条件；关键统计定义或限制”的顺序。正文先提出要回答的问题，再引用图、解释机制，最后说明结论边界。不要把“主策略平均费用更低”写成“所有风险指标全面占优”。

当前图形角色如下：

| 图名 | 回答的问题 |
| --- | --- |
| `q1_dispatch` | 能量如何跨时段配置，SOC与机会成本如何约束动作？ |
| `q1_comparison` | 与相同输入基线相比，费用与电量如何变化？ |
| `q1_sensitivity` | 容量、功率、效率的局部经济影响是什么？ |
| `q2_cost_comparison` | 风险余量如何改变普通与紧急费用，收益是否集中在个别月份？ |
| `q2_selected_days` | 固定合同遇到实际偏差时，储能怎样缓冲？ |
| `q2_sensitivity` | 四日局部重新规划对参数如何响应？ |
| `q2_risk_tradeoff` | 平均节费是否伴随尾部改善，微小优势是否稳定？ |
| `q2_boundary` | 同参数下跨日规划如何改变平均SOC及充电时序？ |
| `q3_selected_days` | 新预报到来后合同如何相对0:00计划调整，紧急购电是否减少？ |
| `q3_information_value` | 哪些调整时点值得引入，外部预报与本地预测融合后误差如何变化？ |
| `q4_prices` | 实时电价的日级与日内结构如何，因果预测能达到什么精度？ |
| `q4_costs` | 实时价结算下价格预测、日内修正与合同调整各值多少？ |

问题三合同上下文固定：0:00计划为蓝色点线、最终合同为蓝色实线、实际净负荷灰色虚线、紧急购电朱橙纹理；预报误差条形中附件3为金色、本地趋势为深灰纹理、融合为蓝色。

跨日对照上下文固定：B48蓝色实线、同参24小时灰色虚线、A替代成本紫色点划线；均值曲线不冒充实际单日。费用差可正可负，不为“升级”隐藏不利结果。

## 6. 新图代码模板

以下仅为接口示意，`x`、`y`必须来自有出处的核验数据。

```python
import matplotlib.pyplot as plt
from vis.style import C, apply_paper_style, figure_size, panel, clean_axis, save_figure

apply_paper_style()
fig, ax = plt.subplots(figsize=figure_size(70), layout="constrained")
ax.plot(x, y, color=C["grid"], marker="o", label="风险策略")
ax.set(xlabel="参数及单位", ylabel="指标及单位")
clean_axis(ax)
panel(ax, "a", "描述性短标题")
ax.legend()
save_figure(fig, output_folder, "q3_example", "数据来源、条件与统计定义")
plt.close(fig)
```

网页中的数据图同样继承语义颜色与阶梯时间含义；网页字号以屏幕可读性为准，不机械套用印刷pt。网页不依赖外部在线字体或绘图库。

## 7. 发布、溯源与验收

运行 `make figures` 从问题一、二最近成功数值归档重绘，不触发优化。每次保存独立 `output/runs/visuals/<时间戳>/`，包括绘图代码、样式配置、上一次公开图、图形及数值输入哈希。原数值归档与结果工作簿前后哈希必须一致。

固定入口：`output/visualization-gallery.html`、`output/figures/`及两个问题的交互网页。每图同时导出PDF、保留文字对象的SVG和400 dpi PNG；配套 `.style.json` 记录尺寸、版本和导出前检查。

验收清单：

- [ ] `make test`通过；当前8组图均可重建。
- [ ] 字号不低于8 pt，文字不越出画布；自动检查不替代人工重叠检查。
- [ ] PDF字体已嵌入，无Type 3字体；曲线和坐标保持矢量。
- [ ] 彩色与灰度预览能辨识变量；图例不覆盖峰值、误差线或关键注释。
- [ ] 正文插图100%尺寸可读，图注与a–h编号一致，无裁切、缺字或跨页异常。
- [ ] 区间定义、单位、时间边界与数字同表格及工作簿一致。
- [ ] 修改和检查已记录于AI使用说明；最终人工复核由参赛队完成。
